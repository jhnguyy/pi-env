For correspondence that you write or post on the user's behalf, prefix agent-authored text with 🤖:. If the user supplies the message, keep their words first and unchanged. Put any agent-authored context after a blank line, starting with 🤖:. If the message is entirely agent-authored, start it with 🤖:. Do not add context when none is needed. This applies to email, chat messages, and issue or pull-request comments. It does not apply to routine replies to the user, code, or machine syntax.
