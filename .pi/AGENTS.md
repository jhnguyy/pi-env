# pi-env

Dotfiles repo registered as a pi package. Extensions and skills are loaded directly from this repo by pi's package manager.

Setup maintains the global guidance block in `~/.pi/agent/AGENTS.md` from `setup/templates/AGENTS.md`. It preserves content outside the managed markers. Keep root `AGENTS.md` specific to this project. Put setup and runtime intent in `README.md`. Put workflow and package rules in `CONTRIBUTING.md`.
